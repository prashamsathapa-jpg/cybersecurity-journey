# Day 5 - Linux Users, Root & Privileges

## What I learned today:
Linux uses different users with different permission levels. The root user has full control over the system.

---

## Key commands:
- whoami → shows current user
- id → shows user and group info
- sudo whoami → shows root access
- cat /etc/passwd → lists system users

---

## Key concepts:
- User: normal account with limited access
- Root: superuser with full system control
- sudo: temporary elevated permissions

---

## Security importance:
If an attacker gains root access, they have full control over the system.

---

## Conclusion:
I learned how Linux users and root privileges work and why controlling access is critical in cybersecurity.
